# Lotic

Lotic is a lightweight framework for Solana built on top of [Pinocchio](https://github.com/anza-xyz/pinocchio/), which serves as its sole dependency. For data deserialization, Lotic follows the [Borsh](https://borsh.io/) specification.

Also, when you use `Lotic`, the only crate your compiled Solana program depends on is `Pinocchio`.
