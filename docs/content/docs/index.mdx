---
title: Hello Solana
description: Lotic is a new minimal Solana program development framework based on Pinocchio.
---

The core design philosophy of Lotic is to stay as close as possible to writing programs directly in Pinocchio.

When expanded, Lotic generates code that is intended to resemble optimized Pinocchio codes,
with the goal of remaining close to what a hand-written version might look like.
